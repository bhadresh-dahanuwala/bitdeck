# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report vulnerabilities privately via GitHub's [**"Report a vulnerability"**](https://github.com/bhadresh-dahanuwala/bitdeck/security/advisories/new) button on the repository's **Security** tab. Include a clear description of the issue and steps or a minimal reproduction to demonstrate it.
